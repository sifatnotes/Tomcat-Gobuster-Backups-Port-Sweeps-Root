## Learning Path

A practical progression through this collection:

1. Begin with **Port Sweep Secrets** to understand network discovery.
2. Move into **Tomcat Trail Enumeration** and other Tomcat investigation labs.
3. Study backup discovery using **Backup Breach** and the **Gobuster Trail** challenge.
4. Explore Tomcat Manager concepts.
5. Connect backup and application findings with root-focused challenges.
6. Finish with **Corrosion 2: Tomcat to Root** as a broader Tomcat privilege-escalation exercise.

## How to Use the Labs

Use these labs only in authorized environments such as CTF platforms, personal virtual machines, or intentionally vulnerable training systems.

For each challenge:

1. Review the lab objective.
2. Identify the relevant application or service.
3. Perform authorized reconnaissance and enumeration.
4. Investigate exposed files, backups, configurations, or application functionality.
5. Document discovered security weaknesses.
6. Relate the findings to defensive security practices.
7. Record lessons learned for future penetration-testing exercises.

Do not test these techniques against systems without explicit authorization.
